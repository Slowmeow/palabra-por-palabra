# Palabra por palabra

Личная читалка испанского: все слова кликабельны, у каждого свой уровень знания от 5 до 1, а Claude пишет перевод, произношение, происхождение, историю слова, факт и объяснение, почему это слово стоит именно в этом месте текста. Всё хранится в вашей базе данных.

Сайт — обычные файлы, без сборки. Хостинг: GitHub Pages. База данных и вход: Supabase. Оба бесплатны. Запросы к Claude оплачиваются отдельно по API.

Адрес сайта после публикации: **https://slowmeow.github.io/MyOwnReading/**

---

## Быстрый старт: три шага

1. **Выложить файлы** в репозиторий https://github.com/Slowmeow/MyOwnReading и включить Pages (пункты 5 ниже).
2. **Создать базу** в Supabase и выполнить `supabase/schema.sql` (пункты 1–3).
3. **Открыть сайт**, ввести адрес базы и publishable key прямо на первом экране, войти и вставить ключ Anthropic в настройках.

Редактировать файлы руками не обязательно: `config.js` можно оставить пустым, сайт спросит значения сам и запомнит их в браузере. Если хотите, чтобы не спрашивал на новом устройстве — впишите их в `config.js` позже через веб-редактор GitHub.

## Что нужно один раз настроить

Порядок такой: сначала база (Supabase), потом сайт (GitHub), потом ключ Claude.

### 1. Создайте проект в Supabase

1. Зайдите на supabase.com, создайте аккаунт и новый проект (регион ближе всего — Frankfurt или Amsterdam).
2. Придумайте и сохраните пароль базы данных. Он пригодится, если что-то пойдёт не так.
3. Дождитесь, пока проект запустится (пара минут).

### 2. Создайте таблицы

1. В проекте откройте **SQL Editor** → **New query**.
2. Скопируйте весь файл `supabase/schema.sql` и вставьте в окно.
3. Нажмите **Run**. Должно появиться «Success».

### 3. Создайте себе аккаунт и закройте регистрацию

1. **Authentication** → **Users** → **Add user** → **Create new user**.
2. Введите свою почту и пароль, включите «Auto Confirm User», создайте.
3. **Authentication** → **Sign In / Providers** (или Settings) → выключите **Allow new users to sign up** и сохраните.

Теперь зарегистрироваться на вашем сайте не может никто. Войти можно только этим аккаунтом.

### 4. Возьмите два значения для config.js

1. В проекте нажмите **Connect** (или **Project Settings** → **API Keys**).
2. Скопируйте **Project URL** (`https://…supabase.co`) и **publishable key** (начинается с `sb_publishable_`).
3. Откройте файл `config.js` и вставьте их в кавычки.

Эти два значения можно спокойно выкладывать в открытый репозиторий: без логина и пароля они ничего не открывают, потому что доступ к строкам защищён политиками из `schema.sql`.

**В `config.js` нельзя вставлять ключ Anthropic (`sk-ant-…`).** Его вводят в настройках самого сайта, и он остаётся в вашем браузере.

### 5. Выложите сайт на GitHub Pages

Есть два пути. Выберите один.

**Путь А — через браузер, ничего устанавливать не нужно.**

1. Распакуйте архив. Откройте папку: внутри лежат `index.html`, `styles.css`, `config.js`, `README.md` и папки `js` и `supabase`.
2. Откройте https://github.com/Slowmeow/MyOwnReading, нажмите **uploading an existing file**.
3. Перетащите в окно все эти файлы и обе папки (`js` и `supabase`) — именно содержимое папки с сайтом, а не саму папку целиком. Нажмите **Commit changes**.
4. **Settings** → **Pages** → Source: **Deploy from a branch**, ветка **main**, папка **/ (root)**, **Save**.
5. Через минуту сайт откроется по адресу https://slowmeow.github.io/MyOwnReading/

Папку `.github` этим способом загрузить не получится: проводник прячет папки, которые начинаются с точки. Она нужна только для автопинга базы, её можно добавить позже (см. пункт 7).

**Путь Б — через git, если он у вас установлен.**

```bash
cd путь/до/распакованной/папки
git init -b main
git add -A
git commit -m "Palabra por palabra"
git remote add origin https://github.com/Slowmeow/MyOwnReading.git
git push -u origin main
```

Затем **Settings** → **Pages** → Source: **GitHub Actions**. Публикация пойдёт сама, workflow уже лежит в `.github/workflows/deploy.yml`.

Репозиторий может оставаться публичным: секретов в файлах нет, а данные закрыты паролем и политиками базы.

### 6. Получите ключ Claude API

1. Зайдите на console.anthropic.com, пополните баланс (минимум обычно $5).
2. **API Keys** → **Create Key**, скопируйте ключ целиком.
3. Откройте свой сайт, войдите, нажмите шестерёнку → вставьте ключ → «Сохранить ключ» → «Проверить».

Оплата API не связана с подпиской claude.ai: это отдельный счёт, деньги списываются за токены.

### 7. Держите базу живой

Бесплатный проект Supabase засыпает после недели без обращений. Если вы читаете регулярно, этого не случится.

Чтобы подстраховаться, добавьте автопинг:

1. В репозитории **Add file** → **Create new file**, в поле имени введите `.github/workflows/ping.yml` (слеши сами создадут папки).
2. Вставьте содержимое одноимённого файла из архива и сохраните.
3. **Settings** → **Secrets and variables** → **Actions** → **New repository secret**: создайте `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY` с теми же значениями, что вводили на сайте.

GitHub будет будить базу раз в три дня.

## Как пользоваться

- **Добавить главу** — плюс в шапке. Вставьте текст на испанском. Галочка «склеивать строки» нужна, когда текст скопирован из PDF и разорван по строкам. Перед сохранением видно, сколько в главе новых для вас слов.
- **Уровни 1–5.** Каждое новое слово начинается с 5 — не знаю. Нажмите на слово и выберите уровень кнопкой или клавишами 1–5. Стрелки ← → переводят к соседнему слову. Уровень 1 — выучено, такое слово перестаёт гореть.
- **Подсветка.** Кнопка с маркером в шапке переключает: все слова / только неизученные / никакой подсветки. Чем ниже уровень, тем бледнее слово.
- **Быстрый словарь** — перевод, произношение русскими буквами и МФА появляются сразу. Для всей главы их можно подготовить заранее кнопкой «Подготовить словарь»: дешёвая модель разбирает слова пачками по 60.
- **Подробный разбор** — кнопка «Разобрать слово с Claude». Даёт происхождение, историю, факт, родственные слова, мнемонику и объяснение, почему слово стоит именно здесь. Если включён показ размышлений, видно, как модель думает.
- **Правки.** Любое поле можно переписать вручную: кнопка «Редактировать» в карточке. Есть и свои заметки к слову. «Перегенерировать» позволяет добавить пожелание, например «сделай факт жутче».
- **Мой словарь** — все слова с поиском и фильтром по уровням. **Прогресс** — сколько выучено, что сделано за неделю, сколько потрачено на API.

## Выбор модели

В настройках выбирается модель и глубина размышления:

| Модель | Цена за млн токенов (вход / выход) | Когда брать |
|---|---|---|
| Claude Fable 5.1 | $10 / $50 | самый глубокий разбор, всегда думает перед ответом |
| Claude Opus 5 | $5 / $25 | сильная и заметно дешевле, хороший выбор по умолчанию |
| Claude Sonnet 5 | $2 / $10 | быстро и дёшево, качества обычно хватает |
| Claude Haiku 4.5 | $1 / $5 | для быстрого словаря |

Глубина размышления — от низкой до максимальной. Максимальная даёт более продуманный разбор, но думает дольше и стоит дороже. Для одного слова обычно достаточно высокой. Можно вписать и любой другой ID модели через пункт «Другая модель».

## Резервные копии

На бесплатном тарифе Supabase не делает копий. Раз в пару недель заходите в настройки и нажимайте «Скачать копию»: получится один JSON со всеми главами, словами, уровнями и карточками. Его же можно загрузить обратно кнопкой «Загрузить копию».

## Что стоит знать про безопасность

- Данные закрыты входом по почте и паролю, и политиками базы: каждый видит только свои строки.
- Ключ Anthropic лежит в `localStorage` вашего браузера и уходит прямо в Anthropic. Это нормально для личного сайта, но не открывайте сайт с чужого компьютера и не вставляйте ключ туда, откуда не сможете его удалить. Если ключ утёк — отзовите его в консоли Anthropic, это одна кнопка.
- Не публикуйте `sb_secret_…`: секретный ключ Supabase обходит все политики. На сайте он не нужен.
